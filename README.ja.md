# exif-viewer

JPEGファイルのEXIFメタデータを表示する、シンプルなクライアントサイドのWebツールです。画像をドラッグ＆ドロップするだけでデータを確認できます。ファイルがサーバーにアップロードされることは一切ありません。

## デモ

**[ライブデモ](https://code4fukui.github.io/exif-viewer/)**

インターフェースは最小限に抑えられています。JPEGファイルをドロップゾーンにドラッグ＆ドロップすると、抽出されたすべてのEXIFデータがテーブルで表示されます。

![画像のEXIFデータを表示するexif-viewer UIのスクリーンショット](https://code4fukui.github.io/exif-viewer/ogp.jpg)

## 機能

- **クライアントサイド処理:** 画像はブラウザ上で直接処理されます。ファイルがサーバーにアップロードされることはありません。
- **シンプルなテーブル表示:** EXIFデータは、タグと値の2列のすっきりとしたテーブルで表示されます。
- **スマートフォーマット:** 有理数（シャッタースピードや絞り値など）を正しくフォーマットし、メタデータ内のURLをクリック可能なリンクに変換します。
- **ファイル検証:** `.jpg`および`.jpeg`ファイルを受け付け、無効なファイル形式や破損したデータに対しては明確なアラートを表示します。

## 使い方

1. [デモページ](https://code4fukui.github.io/exif-viewer/)を開きます。
2. `.jpg`または`.jpeg`ファイルをページにドラッグ＆ドロップします。
3. EXIFデータが即座にテーブルで表示されます。

## クレジット

このツールは、以下のオープンソースプロジェクトを使用して構築されています。

- **EXIF解析:** [exif-js](https://github.com/taisukef/exif-js/)
- **UIフレームワーク:** [Bootstrap](https://getbootstrap.com/)
- **関連プロジェクト:** [jpgbeauty](https://code4fukui.github.io/jpgbeauty/)
